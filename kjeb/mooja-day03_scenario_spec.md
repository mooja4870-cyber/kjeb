# Part 1: Scenario (scenario.md)

## 시나리오 1: 민지의 새 동네 치과 찾기

### 배경
민지(32세)는 한 달 전 일산에서 판교로 이사했다. 어금니가 시려서 치과를 가야 하는데, 새 동네라 어디를 가야 할지 모른다. 예전에 일산에서 다니던 치과는 양심적이었는데, 판교에서도 그런 곳을 찾고 싶다.

### 사용자 여정

```
1. 앱을 연다
   └─ GPS가 자동으로 현재 위치(판교)를 감지
   └─ 상단에 "📍 판교동 기준" 표시

2. "치과" 탭을 누른다
   └─ 이미 선택되어 있음 (기본값)

3. "🔍 판교동 치과 검색" 버튼을 누른다
   └─ 2초 후 15개 치과 목록이 나타남
   └─ "✅ 15개 치과 발견 · 안심 9곳"

4. 목록을 훑어본다
   └─ 💚 안심 추천 (3곳) — 상단에 표시
   └─ ✅ 부정 언급 없음 (6곳)
   └─ ⚠️ 일부 부정 언급 (4곳)
   └─ 🔴 주의 필요 (2곳)

5. 첫 번째 "💚 안심 추천" 치과를 탭한다
   └─ 안심 점수: 97
   └─ 긍정 키워드: "양심적", "필요한 것만", "꼼꼼하게"
   └─ 부정 키워드: 0개
   └─ 전화번호, 주소, 네이버 링크 표시

6. "🗺️ 지도" 버튼을 눌러 위치를 확인한다
   └─ 걸어서 10분 거리

7. 전화를 걸어 예약한다
```

### 결과
민지는 **30초 만에** 판교에서 양심적이라는 평가를 받는 치과를 찾았다. 세컨드 오피니언을 위해 여러 곳을 돌아다닐 필요가 없었다.

## 시나리오 2: 상철의 정형외과 선택

### 배경
상철(55세)은 허리 통증이 2주째 계속된다. 과거에 다른 정형외과에서 불필요한 MRI와 시술을 권유받아 200만원을 쓴 적이 있어, 이번에는 양심적인 곳을 찾고 싶다.

### 사용자 여정

```
1. 앱을 열고, "정형외과" 탭을 선택한다

2. 위치를 "고양시 일산서구"로 변경한다
   └─ 📍 변경 클릭 → 경기 → 고양시 일산서구 → 주엽동
   └─ "📍 주엽동 기준" 으로 변경됨

3. "🔍 주엽동 정형외과 검색" 버튼을 누른다
   └─ 3초 후 12개 정형외과 목록

4. "💚 안심 추천" 필터를 누른다
   └─ 2곳만 표시됨

5. 첫 번째 병원을 탭한다
   └─ 안심 점수: 95
   └─ 긍정 키워드: "보존치료", "경과관찰", "설명을 잘"
   └─ 부정 키워드: 0개
   └─ 설명: "비수술 치료 중심, 환자 상태에 맞는 보존적 치료"

6. 두 번째 병원도 확인한다
   └─ 안심 점수: 91
   └─ 긍정 키워드: "양심적", "필요한 것만"

7. 두 곳을 비교한 뒤, 가까운 첫 번째 병원을 선택한다

8. "🔗 네이버" 링크를 눌러 상세 리뷰를 추가로 확인한다
```

### 결과
상철은 이전의 **과잉진료 경험을 반복하지 않고**, 보존치료 중심의 정형외과를 선택했다.

## 시나리오 3: 영순의 간단한 병원 찾기

### 배경
영순(68세)은 무릎이 아파서 아들에게 전화했다. 아들이 "안심 병원 찾기 앱을 깔아드렸으니 그거 쓰세요"라고 했다.

### 사용자 여정

```
1. 앱을 연다
   └─ 큰 아이콘과 간결한 화면
   └─ GPS 자동 감지: "📍 마두동 기준"

2. "정형외과" 큰 아이콘을 누른다

3. 초록색 검색 버튼을 누른다

4. 목록이 나온다
   └─ 맨 위에 💚 마크가 있는 병원이 보임
   └─ "안심 추천" 이라는 글자가 눈에 들어옴

5. 첫 번째 병원을 누른다
   └─ 전화번호가 크게 보임
   └─ 📞 버튼을 누르면 바로 전화 연결
```

### 결과
영순은 **복잡한 과정 없이 3번의 탭**으로 안심 병원을 찾고 전화를 걸었다.

## 시나리오 4: 지도에서 주변 병원 탐색

### 배경
현우(28세)는 출장 중 갑자기 이가 아파왔다. 낯선 도시에서 급하게 치과를 찾아야 한다.

### 사용자 여정

```
1. 앱을 열고 GPS 자동 감지

2. "치과" 선택 → 검색

3. "🗺️ 지도" 탭으로 전환
   └─ 현재 위치 주변에 마커가 표시됨
   └─ 초록 마커(안심) / 노랑 마커(주의) / 빨강 마커(경고)
   └─ 각 마커에 안심 점수가 표시됨

4. 가장 가까운 초록 마커를 탭
   └─ 팝업에 병원명, 거리, 안심 점수 표시

5. 팝업의 전화번호로 연락하여 방문
```

### 결과
낯선 도시에서도 **지도 한 눈에** 안심 병원의 위치와 점수를 파악하고, 가장 가까운 곳을 빠르게 선택했다.

## Edge Case 시나리오

### E1: 검색 결과가 없는 경우
- 시골/읍면 지역에서 "신경외과" 검색 → 0건
- 대응: "주변에 신경외과를 찾을 수 없습니다. 검색 범위를 넓혀보세요." 메시지 + 상위 지역으로 재검색 유도

### E2: 모든 병원이 "정보 부족"인 경우
- 네이버 API에서 description이 모두 빈 값
- 대응: "리뷰 데이터가 충분하지 않아 안심 점수를 산출할 수 없습니다. 네이버에서 직접 리뷰를 확인해주세요." + 네이버 링크 제공

### E3: GPS 권한 거부
- 사용자가 위치 권한을 허용하지 않음
- 대응: 지역 선택 모달 자동 오픈 → 수동으로 지역 설정 가능

### E4: 인터넷 연결 없음
- 오프라인 상태에서 앱 실행
- 대응: "인터넷 연결이 필요합니다" 안내 + 마지막 검색 결과 캐시 표시 (향후)

# Part 2: Success Criteria (success.md)

## 기능 명세 (Functional Spec)

### F1: 위치 기반 병원 검색

| 항목 | 명세 |
|------|------|
| 위치 입력 방식 | GPS 자동 감지 / 수동 지역 선택 (시도→시군구→읍면동) |
| 검색 API | 네이버 지역검색 API |
| 검색 전략 | 다중 쿼리 동시 호출 (지역+구+동 변형) → 중복 제거 → 병합 |
| 결과 수 목표 | 지역당 15~25개 |
| 응답 시간 | 5초 이내 |
| 정렬 기준 | 안심 점수 내림차순 → 거리 오름차순 |

### F2: 진료과목 선택

| 항목 | 명세 |
|------|------|
| 지원 과목 수 | 11개 |
| 1차 노출 | 8개 (치과, 정형외과, 신경외과, 이비인후과, 내과, 소아과, 안과, 산부인과) |
| 2차 노출 (더보기) | 3개 (피부과, 비뇨의학과, 한의원) |
| UI | 4열 그리드, 아이콘 + 텍스트 |

### F3: 안심 점수 산출

| 항목 | 명세 |
|------|------|
| 데이터 소스 | 네이버 검색 결과의 title + description + category |
| 부정 키워드 | 30개+ (과잉진료, 바가지, 불필요한, 수술 강요 등) |
| 긍정 키워드 | 22개+ (양심적, 착한 진료, 보존치료, 꼼꼼 등) |
| 점수 산출 로직 | 부정 0개 + 긍정 3개 이상 → 안심 추천 (95~100점) |
|  | 부정 0개 + 긍정 1~2개 → 부정 없음 (85~95점) |
|  | 부정 0개 + 긍정 0개 → 부정 없음 (80점) |
|  | 부정 1개 → 일부 언급 (55점) |
|  | 부정 2개 이상 → 주의 필요 (10~40점) |
| 등급 | 💚 안심 추천 / ✅ 부정 없음 / ⚠️ 일부 언급 / 🔴 주의 필요 / 🔍 정보 부족 |

### F4: 결과 표시 (목록 뷰)

| 항목 | 명세 |
|------|------|
| 카드 정보 | 병원명, 주소, 거리(m), 안심 배지+점수, 카테고리 |
| 카드 확장 시 | 안심 점수 상세, 부정/긍정 키워드 수, 설명 텍스트, 키워드 하이라이트, 전화번호, 네이버 링크 |
| 필터 | 💚 안심 추천만 / ✅ 안심+없음 / 📋 전체 |

### F5: 결과 표시 (지도 뷰)

| 항목 | 명세 |
|------|------|
| 지도 엔진 | Leaflet + CartoDB Voyager 타일 |
| 마커 색상 | 등급별 (초록/연두/노랑/빨강/회색) |
| 마커 뱃지 | 안심 점수 숫자 표시 |
| 팝업 | 병원명, 거리, 안심 배지, 전화번호 |
| 내 위치 | 파란 점 마커 + 바운스 애니메이션 |
| 목록↔지도 연동 | 마커 클릭 → 목록 하이라이트 / 목록 🗺️ 클릭 → 지도 이동+팝업 |

### F6: 지역 선택

| 항목 | 명세 |
|------|------|
| UI | 하단 모달, 3단계 드릴다운 |
| 단계 | 시/도 → 시/군/구 → 읍/면/동 |
| 지원 지역 | 서울, 경기, 인천, 부산, 대구, 대전, 광주, 세종, 제주 (9개 시도) |
| GPS 대체 | "📡 GPS" 버튼으로 현재 위치 자동 감지 |
| 브레드크럼 | 선택 경로 실시간 표시 |

## 성공 기준 (Definition of Done)

### MVP 완료 기준 (모두 충족 시 MVP 완료)

- [ ] 11개 진료과목 모두 검색 가능
- [ ] GPS 위치 감지 정상 작동
- [ ] 수동 지역 선택 (9개 시도) 정상 작동
- [ ] 검색 결과 15개 이상 (서울/경기 주요 지역 기준)
- [ ] 안심 점수 산출 및 등급 분류 정상 작동
- [ ] 목록 뷰와 지도 뷰 전환 정상
- [ ] 목록↔지도 연동 (마커↔카드) 정상
- [ ] 전화번호 표시 및 네이버 링크 연결
- [ ] Android APK 빌드 및 실기기 설치 성공
- [ ] 검색 응답 시간 5초 이내

### 품질 기준

| 테스트 유형 | 기준 |
|------------|------|
| 기능 테스트 | 위 체크리스트 100% 통과 |
| 키워드 분석 정확도 | 부정 키워드 포함 리뷰를 90% 이상 탐지 |
| 거리 계산 정확도 | 실제 거리 대비 오차 10% 이내 |
| UI 반응성 | 모든 터치에 200ms 이내 반응 |
| 크래시 | 주요 시나리오에서 크래시 0건 |
